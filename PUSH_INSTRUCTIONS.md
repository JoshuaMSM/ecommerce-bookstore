Push Instructions

1. Create a new GitHub repository (e.g., `bookstore-backend`).
2. Add the remote:

```bash
git remote add origin https://github.com/<your-username>/bookstore-backend.git
git branch -M main
git push -u origin main
```

3. After pushing, copy the repo URL and paste it in the video description field.
